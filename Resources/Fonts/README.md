# Patrick Hand

Patrick Hand Regular by Patrick Wagesreiter is bundled unmodified for MORE's short display headings. Body text and controls use native system type. The font supports Latin and Latin Extended, including French accents. SwiftUI scales it relative to the native title styles.

Primary source: https://github.com/google/fonts/tree/main/ofl/patrickhand
Metadata and PostScript name: https://github.com/google/fonts/blob/main/ofl/patrickhand/METADATA.pb
Licence: SIL Open Font License 1.1, preserved in `PatrickHand-OFL.txt`.
Retrieved 15 October 2026. No runtime font request.

PostScript name: `PatrickHand-Regular`.

SHA-256 of the unmodified TTF: `0f173b3e6cb6d1af25babf7f0057c5ac4ee11f9992b0469bb817e967ef4ad0fc`.

The app's Info.plist must list `PatrickHand-Regular.ttf` under `UIAppFonts`. Include this directory's TTF and licence as app resources.
